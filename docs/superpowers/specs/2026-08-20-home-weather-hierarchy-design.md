# 126f 双城天气层级优化设计

日期：2026-08-20

## 目标

管理员主页不再显示主时钟右侧的纽约天气；左侧“双城天气”继续保持深圳龙岗与东莞松山湖双列，但提高可读性和视觉层级，同时不挤压服务矩阵、硬件栏或底部 Dock。

## 设计

- 从当前管理员 `home` 页面配置的 `main-clock.glanceables` 中删除 `weather`，保留 `date`。这是持久配置变更，不使用 CSS 隐藏，因此主时钟不再渲染或请求天气 glanceable。
- 双城天气卡保持现有数据流和组件结构，只调整这张卡的样式：卡头、城市名、天气状态、当前温度、高低温/降雨以及三段预报均放大。
- 当前温度是一级信息；城市名与天气状态是二级信息；高低温、降雨和未来三段预报是三级信息。两座城市继续等宽，中央分隔线保留但降低存在感。
- 卡片高度只小幅增加；1440×900 仍需完整显示左栏内容。窄屏继续使用现有上下堆叠规则。
- 不新增依赖、数据源、动画或替代天气实现，也不改服务矩阵和硬件面板。

## 配置与失败行为

配置更新前读取并保留当前完整 `home` 配置，只对 `columns.middle.main-clock.glanceables.weather` 做一次删除。写回后重新读取验证 `date` 仍存在且 `weather` 不存在；若写入或验证失败，恢复原配置。

天气 API 失败时继续使用现有“暂不可用”状态，不伪造数据。

## 验收

- 管理员 `/home` 不包含 `New York`，主时钟仍显示时间和日期。
- 双城天气为两列；城市名、当前温度和预报比当前线上字号更大，且无截断、重叠或横向溢出。
- 1440×900 桌面和 390px 移动端布局正常；背景继续播放，页面无框架错误覆盖层和相关控制台错误。
- 组件测试、类型检查、Lint 与生产构建通过；发布后 126f 服务和健康检查通过。
